# 仿真资源与装饰贴图变更

本轮处理的是资源可移植性与非必要人物图像；不是对原论文视觉实验的等价复原。

| 资源 | 处理与验证 |
| --- | --- |
| 缺失的 `sitting_human_01` | 用 `tools/make_occupant_proxy.py` 生成厘米单位的简单坐姿方块模型；模型配置、OBJ 注释均明确标注是本地程序化占位物，非原始论文网格。世界文件仍采用原有 0.01 缩放 |
| 未引用的 `aws_Sofa_01.DAE` | 检查场景、URDF/Xacro 和材质引用后，归档到项目外并从工作区移除；实际使用的沙发 visual/collision 文件保留 |
| 桌子碰撞网格 | 删除不参与碰撞几何的缺失贴图依赖，保留几何块的字节内容；不虚构原始纹理 |
| 饮料与三明治材质 | 两个 MTL 的 `texture.png` 引用改为真实存在的 `../materials/textures/texture.png`；保留原版权/CC BY 文字并注明局部修改 |
| 装饰性人物照片、合照和手机界面截图 | 逐张缩略图筛查后，13 个图片文件归档到项目外并删除；13 个相关 DAE/MTL 删除对应图片绑定、使用纯色材质，几何块保持不变 |

327 个原始 PNG/JPG/PSD 做过可读取元数据与缩略图筛查；还解析了 PSD 的 25 个资源块，并在常见文本编码中检查机构/原维护者关键词，未发现这些关键词。没有进行完整的高分辨率 OCR、隐写分析或未知私有数据结构解码。

保留正常商品标签、第三方作者声明、模型来源和许可证。对人物图像没有进行人脸识别或身份推断。原图和改动前材质保存在项目外的本地备份中，不应混入后续公开交付。

具体移除文件和材质清单见 [media_cleanup.json](media_cleanup.json)。当前场景静态资源闭包检查命令为：

```bash
python3 -B tools/check_simulation_resources.py --output artifacts/resources.json
```

该检查从默认 `food_court.sdf` 及两个 foodcourt world 出发，递归解析本地 SDF、DAE、OBJ、MTL 引用。它没有验证全部备用场景、插件二进制加载、SDF 动力学或渲染表现；资源文件存在不等于整个机器人仿真已通过。
